# smart-puck
A Zigbee smart puck with easily configurable options

## Current Plan:
- microcontroller: esp32-h2
- battery/power management: BQ25185 (charger/power path), TPS63900 (buck boost), LC709203F (fuel gauge)
- led: NH-B2020RGBA-GF
- temperature/humidity: SHT45-AD1F-R2
- mmwave: HLK-LD2420
- keyboard switches for buttons (cherry mx style)
- rotary encoder (ec11?)
